# C 输出 token 差异复核

本复核仅描述 C 主矩阵的策略间 token ID 一致性和现有日志可支持的范围，不把 token 一致等同于答案质量，也不从解码差异反推未观测的数值根因。

## 配对统计

| 对照 | 配对数 | 文本 token IDs 完全一致 | 图文 token IDs 完全一致 | 两类均一致 |
|---|---:|---:|---:|---:|
| F 对 N | 144 | 144/144 | 108/144 | 108/144 |
| S 对 N | 144 | 143/144 | 144/144 | 143/144 |
| U 对 N | 144 | 144/144 | 144/144 | 144/144 |

## 差异分布与观察

- F/N 的 36 个图文 token 不一致样本全部来自 512 图负载：L512-D2 和 L512-D6 各 18/36；差异集中在 image index 1、2。各策略内部跨块重复稳定，因此这些差异是策略相关的确定性输出变化，不是 token 级等价。
- 抽查的 16-token 截断解码均描述相同的几何图形，但措辞不同。例如 N 输出以 “circles, squares, triangles” 列举，F 使用 “including circles, squares, and triangles”。受 max-token 截断限制，该样本不能说明完整回答质量或语义质量。
- S/N 仅在 L768-D6、block 2、seed 0 有一个文本序列差异，出现在重复填充的 text lane 5 尾部，表现为 “be” 重复；其余 143/144 配对的文本序列相同，图文序列 144/144 相同。
- U/N 的文本和图文 token IDs 均 144/144 完全相同。
- 当前 C 埋点没有定位 F/N 图文 token 差异或 S 单条文本差异的数值根因。实验校验字段均无错误；因此不能据此声称实现错误，也不能声称跨策略精确输出等价。

## 解释边界与后续处理

性能分析保留所有有效 episode，不因输出措辞差异删除样本；同时把确定性 token divergence 单独披露。下一阶段保持策略间相同的生成配置和输入轨迹，保存完整输出与 token IDs；D 的主要目标是调度与期限，不以 16-token 截断回答评估视觉质量。若后续研究需要质量结论，应另建足够长的输出和人工/自动语义评估设计。
