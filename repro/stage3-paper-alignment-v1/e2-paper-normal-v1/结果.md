# TokenFlow E2 论文正态适配实验结果

日期：2026-10-28（北京时间）。本结果是论文参数未完全公开条件下的**适配对照**，不是对论文原图或原始 artifact 的完整复现。

## 实验条件

- 作者 fork 候选 commit：`e754998d6980656707b9628fb5121a4ac4f985df`；tracked diff SHA256：`1099c3fc37f782c057ad691af9288f22c537384cabf796ef6c3a1e4feea710fd`。论文固定 commit 未确认。
- 模型：`Qwen2-7B-Instruct`，revision `f2826a00ceef68f0f2b946d945ecc0477ce4450c`；RTX 4090 GPU1、TP1、BF16。
- E2 每个 seed 80 个并发突发请求，输入长度均值1024、输出长度均值2048；正态分布按`σ=0.2×均值`适配，非法或越出上下文长度的样本重采样。三 profile 使用相同 seed 工作负载，prompt 来自固定 SHA 的 ShareGPT 首轮文本并经本地 tokenizer 编码。
- 三 profile：plain（chunked关闭，CLI `--chunked-prefill-size -1`）、chunked（2048）、TokenFlow（2048 + `paper_v1` HiCache）。三组均使用同一候选 fork；因此不是官方上游 SGLang 与 TokenFlow fork 的跨仓库比较。
- 实验共尝试9轮、720请求；总计711个响应完成，其中7个完整轮贡献560个可纳入整轮指标的响应，2个未完整 chunked 轮另有151个响应完成。plain 和 TokenFlow 各3/3轮全部完成；chunked 只有 seed103 完整。

`*` 仅 seed103 一轮完整结果。

TokenFlow 对 plain 的三 seed 配对变化先逐 seed 计算相对差，再取算术平均：有效吞吐 **+12.00%**，原始吞吐 **+0.66%**，平均 TTFT **−5.11%**，P99 TTFT **−12.87%**。同时，平均端到端时间 **+2.37%**（变慢），stall fraction 从 **4.72%升至6.21%**（+1.50个百分点）。因此该适配负载下有 TTFT 和有效吞吐改善，但不能概括为所有指标都提升。

seed103 是唯一三 profile 均完整的一组：TokenFlow 有效吞吐586.77 token/s，plain为502.95，chunked为507.97；这只是一个 seed 的观察，不足以代表总体 chunked 对照。

### 隔离复放诊断

从 seed101/request9 与 seed102/request66 原样抽取输入token和目标输出长度，在 chunked=2048 profile下经相同 E1 预热和 `flush_cache` 后分别单请求复放；两条都完成，耗时87.27秒和72.73秒。由此排除单个请求内容或长度本身必然导致失败；现有证据把问题范围缩小到80请求突发并发下的调度/回收状态或该状态下的SSE传输，但尚不能判定具体原因。三 seed的 retraction 事件/请求数为8、12、7，成功的seed103同样发生7次，所以回收次数本身不能解释哪些请求停滞。详见`../chunked-timeout-diagnostic-v1/结果.md`。

## 结论与下一步

- 事实：plain 和 TokenFlow 在此适配负载下均完成全部三 seed；TokenFlow 三轮的有效吞吐和 TTFT 均值优于 plain，平均端到端时间与 stall fraction 更差。
- 限制：chunked 两轮没有完整结果，chunked 只有一个完整 seed；有效吞吐收益与延迟改善尚不足以作为对论文总体数据的复现结论。
- 正确性边界：此前长序列诊断仍未逐层确认暂停恢复 KV 与重算 KV 一致；本轮 E2 结果不消除该限制。
- 按方案门槛，E2仍有未定位的突发期请求停滞，暂不扩展E1/P2/P4，也不盲目重跑两个seed。若继续根因定位，应加短期 request-ID 生命周期日志（retraction、入队、重新prefill/decode、finish/abort五个事件）并复跑冻结的E2 seed101；诊断补丁数据不混入性能统计。

完整轮次指标和逐请求失败详情见`summary.json`与`incomplete-request-details.json`；原始 SSE 文件、服务日志、环境/命令快照、warmup 和资源采样均保留在本目录。
